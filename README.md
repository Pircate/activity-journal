# 我的运动记录

中文静态运动展示页，使用 COROS 真实记录。数据范围：2025 年 10 月 9 日至 2026 年 10 月 8 日。

## 页面内容

- 一年内 244 次运动，217 个运动日。
- 已记录距离累计 7,716.64 公里，运动时长 292 小时 50 分 20 秒。
- 全年每日活动热力图，可切换距离、时长和 COROS 训练负荷。
- 可选择日期查看当天累计指标；热力图支持方向键、Home 和 End。
- 按日期倒序展示一年内的全部运动记录。

## 数据与更新

`docs/activities.json` 是概览、热力图和记录表的统一数据来源。仅保留日期、运动类型、距离、时长与训练负荷，不包含坐标、心率、账号信息或原始活动标识。

COROS 未提供 2 条记录的距离及 28 条记录的训练负荷；缺失值保留为 null，不虚构数值。累计距离仅求和已知距离；按日合并时会显示缺失提示，热力图使用斜线标记缺失。

这是一次性导入的固定记录集，页面显示同步时间，后续按需手动更新。修改数据后执行 `node scripts/build.mjs` 重新生成页面。

## 本地预览与发布

执行 `python3 -m http.server 8787 --bind 127.0.0.1 --directory docs`，访问 `http://127.0.0.1:8787/`。

通过 GitHub Pages 公开托管：[访问我的运动记录](https://pircate.github.io/movement-journal/)。

使用 Node.js 22 或更新版本运行构建脚本。修改数据后执行 `node scripts/build.mjs`，将更新后的源码和 `docs/` 一起提交并推送到 `main` 分支，GitHub Pages 会自动从 `docs/` 发布。

页面资源使用相对路径，无需 Cloudflare、外部 CDN 或服务端接口。
